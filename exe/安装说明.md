# SyncBridge Windows 安装说明

## 文件

- SyncBridge_0.1.0_x64-setup.exe：安装版，适合长期使用。
- SyncBridge_portable.exe：绿色版，双击运行，不需要安装。

## 安装版

1. 双击 SyncBridge_0.1.0_x64-setup.exe。
2. 按安装程序提示完成安装。
3. 启动 SyncBridge。
4. 填写服务器根地址。
5. 使用与手机端相同的邮箱和密码登录。
6. 点击同步，检查日历和便签。

## 绿色版

把 SyncBridge_portable.exe 复制到有写入权限的目录后双击运行。它不会创建开始菜单项或卸载项。

电脑需要兼容的 WebView2 Runtime。如果绿色版窗口空白，优先安装或修复 WebView2 Runtime，或者使用安装版。

## 连接条件

电脑端和手机端必须使用：

- 同一个服务器根地址；
- 同一个邮箱；
- 正确的密码。

电脑端软件本身不等于后台服务；后台不可访问时，客户端只能显示连接或同步失败。
