# SyncBridge 后端部署说明

## 1. 依赖

本归档不包含 Python 解释器。部署机器需要安装 Python 3.10 或更高版本。

进入后端目录：

    cd "C:\Users\<USER>\Desktop\SyncBridge\后端"

创建虚拟环境并安装依赖：

    python -m venv .venv
    .\.venv\Scripts\python.exe -m pip install --upgrade pip
    .\.venv\Scripts\python.exe -m pip install -r requirements.txt

## 2. 数据库路径

默认运行数据库为：

    C:\Users\<USER>\Desktop\SyncBridge\数据库\syncbridge.db

为避免误用其他历史库，建议显式设置环境变量：

    $env:SyncBridge_DB_PATH = "C:\Users\<USER>\Desktop\SyncBridge\数据库\syncbridge.db"
    $env:PYTHONPATH = "C:\Users\<USER>\Desktop\SyncBridge\后端"

## 3. 启动

可以运行：

    .\启动后台服务.bat

该脚本默认监听 8123 端口，并使用后端目录下的 .venv。如果脚本不存在虚拟环境，会尝试自动创建并安装依赖。

也可以手动启动：

    $env:SyncBridge_DB_PATH = "C:\Users\<USER>\Desktop\SyncBridge\数据库\syncbridge.db"
    $env:PYTHONPATH = "C:\Users\<USER>\Desktop\SyncBridge\后端"
    .\.venv\Scripts\python.exe -m uvicorn app.main:app --host 0.0.0.0 --port 8123

本机健康检查：

    http://127.0.0.1:8123/api/v1/health

返回 status: ok 后，再配置 Sakura FRP 将本地 8123 端口映射到公网。

## 4. Sakura FRP

FRP 的本地目标应为：

    127.0.0.1:8123

公网健康接口验证通过后，客户端填写公网服务器根地址，不填写 /api/v1/health。

正式公网使用建议 HTTPS。HTTP 仅适合局域网、校园网或临时测试。

## 5. 数据库备份

停止后台后再复制数据库。归档中已提供：

    ..\数据库\备份\syncbridge_归档_20260920.db

恢复前先备份当前数据库，再替换 数据库\syncbridge.db，然后重新启动后台。

不要在后台运行时直接覆盖正在使用的 SQLite 数据库。

## 6. 不包含的内容

本归档不包含：

- SQLite 软件本身；
- Python 解释器；
- Sakura FRP 客户端；
- HTTPS 证书；
- Docker Desktop；
- Node.js、Rust、Android SDK 和 Gradle。


## 7. 日历提醒（系统弹窗）

后端会在常开电脑上自动按事件时间弹出 Windows 系统通知（Action Center 原生 Toast，带声音，
点击可打开客户端）。无需改动客户端 / 安卓。

### 依赖
requirements.txt 已新增 `windows-toasts`、`win10toast`、`tzdata`。重新安装依赖：

    .\.venv\Scripts\python.exe -m pip install -r requirements.txt

### 行为
- 每个事件按 `reminder_minutes`（如 `[0,5,15,30]`）在「准点 / 提前 N 分钟」触发；
- 未设置 `reminder_minutes` 的事件套用全局默认（默认提前 15 分钟）；
- 已触发记录写入 `reminder_fired` 表，重启 / 重扫不重复弹；错过窗口（>2 分钟）的历史事件不会轰炸；
- 非打包进程首次启动会自动注册 AUMID + 开始菜单快捷方式，使通知被系统识别为「SyncBridge」。

### 开关与配置（环境变量，可选）
- `SyncBridge_REMINDERS_ENABLED=0` 关闭提醒（默认 1 开）；
- `SyncBridge_DEFAULT_REMINDER=15,30` 覆盖全局默认提前量（逗号分隔）；
- `SyncBridge_CLIENT_URL=http://localhost:8123/` 点击通知时打开的地址。

### 生效条件
提醒只在后端进程存活时有效。请以本人账号用 `.bat` 或 `uvicorn app.main:app` 常开运行；
若注册为 Windows 服务（SYSTEM 会话），通知不会出现在你的桌面。

### 验证
写一条 `reminder_minutes=[0,1]` 的事件，等约 1 分钟应在本机屏幕看到弹窗；重启后端后已弹的不重复弹。
